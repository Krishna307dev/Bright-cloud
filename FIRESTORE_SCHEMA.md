# Firestore Schema & Access Control

## Decision

**All primary collections are scoped under `vaults/{vaultId}`.** This unifies USB storage across all physical contributor devices while enabling strict role-based access control (Admin vs. Friends) for Web Viewers.

---

## Collection Tree

```text
vaults/
  {vaultId}/
    settings               (singleton: adminUids, authorizedFriends, metadata)
    sources/
      {sourceId}/          (one per physical USB flash drive)
    files/
      {fileId}/            (one per backed-up file with permissions)
    contentHashes/
      {sha256}/            (one per unique content hash; IMMUTABLE)
    backupJobs/
      {jobId}/             (one per backup session)
    nameReservations/
      {reservationId}/     (atomic filename version locks)
    folderRules/
      {ruleId}/            (granular folder-level access control rules)
```

---

## Roles & Permissions Matrix

| Action | HUMAN_ADMIN (Google) | HUMAN_VIEWER (Google) | DEVICE_UPLOAD (Anonymous Daemon) |
|---|---|---|---|
| **Browse / Search Metadata** | Full Vault Access | Permitted Files/Folders Only | Internal (Dedup/Collision Check) |
| **Download Files from B2** | Full Vault Access | Permitted Files Only | **DENIED (403)** |
| **Manual Web Upload** | Allowed | **DENIED** | N/A |
| **USB Automatic Backup** | N/A | N/A | **ALLOWED** |
| **Edit File Metadata** | Allowed | **DENIED** | Allowed (Job Finalization) |
| **Manage Access / Rules** | Allowed | **DENIED** | **DENIED** |
| **Delete Files / Sources** | Allowed (Admin UI) | **DENIED** | **DENIED** |
| **Access Name Reservations**| Allowed | **DENIED** | **ALLOWED** |

## Document Schemas

### `vaults/{vaultId}/settings`

| Field | Type | Description |
|---|---|---|
| `vaultId` | string | Canonical vault ID (e.g. `"default"`) |
| `adminUids` | string[] | Array of Google UIDs with full owner/admin permissions |
| `authorizedFriends` | string[] | Array of whitelisted friend Google UIDs |
| `createdAt` | timestamp | Vault creation timestamp |
| `updatedAt` | timestamp | Settings last modified timestamp |

**Document ID**: Always `settings` (singleton).

---

### `vaults/{vaultId}/sources/{sourceId}`

| Field | Type | Description |
|---|---|---|
| `sourceId` | string | Stable physical USB fingerprint (`{vendorId}-{productId}-{volumeUuid}`) |
| `volumeUuid` | string? | Filesystem partition volume UUID (e.g. `"8F12-3456"`) |
| `usbVendorId` | number | USB vendor ID |
| `usbProductId` | number | USB product ID |
| `serialNumber` | string? | USB hardware serial number |
| `displayName` | string | Human-readable name for display |
| `firstSeen` | timestamp | First connection timestamp |
| `lastSeen` | timestamp | Most recent connection timestamp |
| `totalFilesBackedUp` | number | Running count of backed-up files |

**Document ID**: `sourceId` = `{vendorId}-{productId}-{volumeUuid}`.

---

### `vaults/{vaultId}/files/{fileId}`

| Field | Type | Description |
|---|---|---|
| `fileId` | string | Auto-generated unique ID |
| `sourceId` | string | Reference to physical USB source |
| `relativePath` | string | Path from USB root (e.g., `"Photos/2026/"`) |
| `originalName` | string | Original filename on USB / uploaded filename |
| `storedName` | string | Stored filename in Backblaze B2 (may be versioned) |
| `b2ObjectKey` | string | Full B2 object key: `backups/{vaultId}/{sourceId}/{relativePath}{storedName}` |
| `storageBackend` | string | `"B2"` |
| `sha256` | string | Content hash (64-char lowercase hex) |
| `size` | number | File size in bytes |
| `lastModified` | number | File last modified timestamp (epoch ms) |
| `mimeType` | string? | MIME type if available |
| `version` | number | 0 = original, 1 = (1), 2 = (2), etc. |
| `status` | string | `"UPLOADED"` |
| `uploadedAt` | timestamp | Server timestamp of upload completion |
| `jobId` | string | Reference to backup job session |
| `isPublicToFriends` | boolean | If `true`, all whitelisted friends can view/download |
| `allowedFriends` | string[] | Explicit array of friend Google UIDs granted access |

**Document ID**: Auto-generated by Firestore (`doc()`).

**Indexes**:
- Composite: `(sourceId, relativePath, originalName)` — for filename collision detection.
- Single-field: `sha256` — for content-based lookup and deduplication.

---

### `vaults/{vaultId}/contentHashes/{sha256}`

| Field | Type | Description |
|---|---|---|
| `sha256` | string | The SHA-256 hash (also the document ID) |
| `fileId` | string | Reference to the canonical file document |
| `b2ObjectKey` | string | Backblaze B2 object key |
| `storageBackend` | string | `"B2"` |
| `size` | number | File size in bytes |
| `storedName` | string | Cloud filename |
| `uploadedAt` | timestamp | When the content was first uploaded to B2 |

**Document ID**: The SHA-256 hash string itself (64-char lowercase hex).  
**Immutability**: Create-only; updates and deletions are strictly rejected.

---

### `vaults/{vaultId}/backupJobs/{jobId}`

| Field | Type | Description |
|---|---|---|
| `jobId` | string | Auto-generated unique ID |
| `sourceId` | string | Reference to source device |
| `state` | string | `SCANNING` / `HASHING` / `DEDUPLICATING` / `UPLOADING` / `COMPLETED` / `FAILED` / `CANCELLED` |
| `startedAt` | timestamp | Job start time |
| `completedAt` | timestamp? | Job completion time |
| `totalFiles` | number | Total files discovered |
| `hashedFiles` | number | Files hashed |
| `skippedFiles` | number | Files skipped (deduplication) |
| `uploadedFiles` | number | Files uploaded to B2 |
| `errorFiles` | number | Files with errors |
| `error` | string? | Job-level error message |

---

### `vaults/{vaultId}/nameReservations/{reservationId}`

| Field | Type | Description |
|---|---|---|
| `reservationId` | string | Composite: `{sourceId}_{relativePath}_{storedName}` |
| `sha256` | string | Content hash of the file being uploaded |
| `b2ObjectKey` | string | Reserved Backblaze B2 object key |
| `sourceId` | string | Source device |
| `relativePath` | string | Directory path |
| `originalName` | string | Original filename |
| `storedName` | string | Reserved cloud filename (may be versioned) |
| `status` | string | `PENDING` / `COMMITTED` / `EXPIRED` |
| `jobId` | string | Backup job |
| `createdAt` | timestamp | When reserved |
| `expiresAt` | timestamp | TTL: `createdAt + 24 hours` |

---

### `vaults/{vaultId}/folderRules/{ruleId}`

| Field | Type | Description |
|---|---|---|
| `folderRuleId` | string | Unique rule ID |
| `relativePath` | string | Folder path (e.g. `"Projects/Confidential/"`) |
| `allowedFriends` | string[] | Array of friend Google UIDs permitted for this folder |
| `updatedAt` | timestamp | Timestamp of rule change |

## Firestore Security Rules Specification

```javascript
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {

    function isAuthenticated() {
      return request.auth != null;
    }

    function isAnonymous() {
      return isAuthenticated() && request.auth.token.firebase.sign_in_provider == 'anonymous';
    }

    function isGoogleUser() {
      return isAuthenticated() && request.auth.token.firebase.sign_in_provider == 'google.com';
    }

    function getVaultSettings(vaultId) {
      return get(/databases/$(database)/documents/vaults/$(vaultId)/settings).data;
    }

    function hasVaultSettings(vaultId) {
      return exists(/databases/$(database)/documents/vaults/$(vaultId)/settings);
    }

    function isAdmin(vaultId) {
      return isGoogleUser() && hasVaultSettings(vaultId) && request.auth.uid in getVaultSettings(vaultId).adminUids;
    }

    function isFriend(vaultId) {
      return isGoogleUser() && hasVaultSettings(vaultId) && request.auth.uid in getVaultSettings(vaultId).authorizedFriends;
    }

    match /vaults/{vaultId} {

      // Vault Settings: Admins write/read; Friends read; Anonymous DAEMONS DENIED (Zero identity leakage)
      match /settings {
        allow read: if isAdmin(vaultId) || isFriend(vaultId);
        allow write: if isAdmin(vaultId);
      }

      // Physical USB Sources: Admin full; Friends read; Anonymous daemon creates/updates/reads its own sourceId
      match /sources/{sourceId} {
        allow read: if isAdmin(vaultId) || isFriend(vaultId) || (isAnonymous() && resource.data.sourceId == sourceId);
        allow create, update: if isAdmin(vaultId) || (isAnonymous() && request.resource.data.sourceId == sourceId);
        allow delete: if false;
      }

      // Files: 
      // - Admin: Full read/write/delete
      // - Friend: Read only if isPublicToFriends or UID in allowedFriends
      // - Anonymous Daemon: Create/update metadata during backup; read files scoped to its current sourceId
      match /files/{fileId} {
        allow read: if isAdmin(vaultId) || (
          isFriend(vaultId) && (
            resource.data.isPublicToFriends == true ||
            request.auth.uid in resource.data.allowedFriends
          )
        ) || (isAnonymous() && resource.data.sourceId != null);
        allow create, update: if isAdmin(vaultId) || isAnonymous();
        allow delete: if isAdmin(vaultId);
      }

      // Content Hash Index: IMMUTABLE after creation (Anonymous & Admin can read by hash for deduplication)
      match /contentHashes/{hashId} {
        allow read: if isAdmin(vaultId) || isFriend(vaultId) || isAnonymous();
        allow create: if isAdmin(vaultId) || isAnonymous();
        allow update, delete: if false;
      }

      // Backup Jobs: Admin full; Friends read; Anonymous daemon creates/updates its job
      match /backupJobs/{jobId} {
        allow read: if isAdmin(vaultId) || isFriend(vaultId);
        allow write: if isAdmin(vaultId) || isAnonymous();
      }

      // Name Reservations: Admin & Anonymous daemon lock mechanism; Friends DENIED
      match /nameReservations/{resId} {
        allow read, write: if isAdmin(vaultId) || isAnonymous();
      }

      // Folder Access Rules: Admin writes/reads; Friends read; Anonymous DAEMONS DENIED
      match /folderRules/{ruleId} {
        allow read: if isAdmin(vaultId) || isFriend(vaultId);
        allow write: if isAdmin(vaultId);
      }
    }

    // Catch-all deny
    match /{document=**} {
      allow read, write: if false;
    }
  }
}
```
